Temporal evolution of forest habitat amount and fragmentation in Europe (1990–2018)

Author

Cyrille Marchant

Introduction

Landscape fragmentation is a major component of landscape change and can affect habitat availability, ecological connectivity and biodiversity. Changes in land cover can modify both the total amount of habitat and its spatial configuration.

This project investigates the temporal evolution of forest habitat amount and fragmentation between 1990 and 2018 using CORINE Land Cover data.

The analysis compares two European regions with contrasting geographic and landscape characteristics: Spain and the Baltic States (Estonia, Latvia and Lithuania). A regular 10 × 10 km grid is used as the spatial unit of analysis. The use of equal-sized cells allows landscape metrics to be compared independently of the size and geometry of administrative units.

The complete workflow is designed to be reproducible. Study areas, years, grid resolution and forest classes are defined as parameters at the beginning of the document and can therefore be modified without rewriting the analysis.

Research question

How did forest habitat amount and landscape fragmentation evolve between 1990 and 2018 in Spain and the Baltic States, and do these regions show different trajectories of landscape change?

Objectives

The analysis has four main objectives:

  1. quantify changes in forest habitat amount between 1990 and 2018;
  2. quantify changes in forest spatial configuration and fragmentation;
  3. identify spatial hotspots of forest loss, gain and fragmentation;
  4. compare temporal trajectories between Spain and the Baltic States.

Project initialization

Required packages

The analysis combines vector and raster geoprocessing, landscape ecology metrics, data manipulation and interactive visualization.

sf is used for vector spatial data, terra for raster processing, and landscapemetrics for the computation of landscape metrics. European administrative boundaries are obtained with giscoR. The here package is used to construct relative file paths, avoiding computer-specific working directories.

Reproducible project root

No absolute working directory is used in this project.

Instead of using setwd(), all paths are constructed from the root of the RStudio project with here::here(). Consequently, another user can clone the GitHub repository in any directory and run the workflow without modifying local paths.

Project parameters

All major methodological parameters are retrieved from the YAML header. These values constitute the main settings that can be modified to reproduce the workflow for other areas or spatial resolutions.

forest_classes <- as.integer(unlist(params$forest_classes))

analysis_parameters <- tibble::tibble(
  parameter = c(
    "Study regions",
    "Years",
    "Grid resolution",
    "Habitat focus",
    "CORINE forest classes",
    "Cache"

  value = c(
    paste(study_regions, collapse = ", "),
    paste(years, collapse = ", "),
    paste0(grid_km, " × ", grid_km, " km"),

Version control and GitHub

Git ignore configuration

Raw CORINE Land Cover rasters can be very large and should not normally be stored directly in the GitHub repository.

The .gitignore file therefore excludes raw CORINE files and temporary cache files while retaining the Quarto source code and derived lightweight outputs.

Data

Study area

The study area consists of Spain and the three Baltic States:

  • Spain (ESP);
  • Estonia (EST);
  • Latvia (LVA);
  • Lithuania (LTU).

European boundaries will be downloaded directly from GISCO rather than manually stored in the project. This improves reproducibility and makes it possible to adapt the workflow to other European countries.
